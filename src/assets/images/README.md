# Advisor visuals

- agent-visiting-card.jpeg: visiting card supplied by the site owner; used in the hero.
- agent-consultation-animated.svg: supplied consultation illustration for the About section.
- agent-consultation-static.svg: non-animated alternative for prefers-reduced-motion.

The paths are controlled by siteConfig.visuals. Keep the reduced-motion image in
sync when replacing the animation. The supplied visiting card is shown unchanged;
contact buttons continue to use siteConfig.contact, not text extracted from the card.
